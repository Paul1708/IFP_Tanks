# IFP Tanks Game

This 2D pixel art tank game is built using Godot. The objective is to navigate your tank through levels, destroy all enemy tanks, and advance. If the player's tank is destroyed, they respawn at the last checkpoint. Upgrades and different bullet types help the player reach the end.

## Core Gameplay

1. **Destroy All Enemies**: Each level is complete once all enemy tanks are eliminated.
2. **Checkpoint System**: Upon destruction, the player returns to the most recent checkpoint.
3. **Tank Upgrades**: Earn points or resources to upgrade speed, health, and firepower.
4. **Bullet Types**: Purchase various projectile types from the shop to change combat tactics:
   - **Default**
   - **Bouncing**
   - **Grenade**
   - **Homing**
   - **Laser**
